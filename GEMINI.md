# Antigravity Context — Rubens Barbosa Portfolio

Este projeto é dividido em dois módulos essenciais:

1. **`/portifolio-ux` (Planejamento e Design UX):**
   - Contém o layout oficial do portfólio no arquivo Pencil [`ux-portifolio.pen`](file:///portifolio-ux/ux-portifolio.pen).
   - Contém a captura de tela renderizada do layout [`ux-portifolio-preview.png`](file:///portifolio-ux/ux-portifolio-preview.png).
   - Contém a documentação de UX, paleta de cores, tipografia e scripts de automação em [`portifolio-ux/README.md`](file:///portifolio-ux/README.md).
   - O design segue a temática Cyberpunk / Dark Navy / High-Performance HUD inspirada no carro do Rocket League.

2. **`/portifolio-app-front` (Aplicação Web Frontend):**
   - Aplicação Next.js 16 (App Router) + React 19 + Tailwind CSS v4 + TypeScript + Biome.
   - Todo componente desenvolvido deve ser uma tradução fiel do layout e das diretrizes de `portifolio-ux`.
   - Consulte [`portifolio-app-front/AGENTS.md`](file:///portifolio-app-front/AGENTS.md) para detalhes técnicos da aplicação.
