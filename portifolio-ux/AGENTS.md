# Instruções para Agentes — Pasta `/portifolio-ux`

Esta pasta é o repositório central de **design, UX e especificações visuais** do portfólio de **Rubens Barbosa**.

---

## 📌 Papel Desta Pasta no Projeto
- O código da aplicação web reside em [`/portifolio-app-front`](file:///portifolio-app-front).
- Esta pasta (`/portifolio-ux`) armazena o **planejamento do layout**, os wireframes, a identidade visual e as ferramentas de suporte ao design.

---

## 👁️ Como Visualizar o Design
1. **Visualização Rápida (Print em PNG):**
   - Inspecione diretamente a imagem renderizada: [`ux-portifolio-preview.png`](file:///portifolio-ux/ux-portifolio-preview.png).
2. **Documento Nativo (Pencil / pen.dev):**
   - O arquivo do layout é [`ux-portifolio.pen`](file:///portifolio-ux/ux-portifolio.pen). Ele pode ser aberto no app desktop Pencil ou inspecionado/manipulado via scripts Node.js nesta pasta quando o app estiver em execução.
